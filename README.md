## 🚀 Запуск проекта

```bash
# 1. Клонировать репозиторий
git clone [https://github.com/thesamecrone/ATT.git](https://github.com/thesamecrone/ATT.git)
cd ATT

# 2. Установить зависимости
npm install

# 3. Запустить в режиме разработки
npm run dev
